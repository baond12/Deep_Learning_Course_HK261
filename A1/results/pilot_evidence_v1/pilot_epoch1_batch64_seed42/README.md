# Kết quả chạy thăm dò A1

Chỉ huấn luyện/xác thực, không đánh giá test. Đây chưa phải kết quả A1.2.

Gửi lại toàn bộ thư mục này hoặc tệp nén. `metrics.json` chứa cấu hình, môi trường, kết quả, lịch sử, đo từng pha và lỗi; `summary.csv` là bảng nhanh; `run_*.json` lưu từng lượt; `split_indices.json` ghi chỉ số chia; `run.log` ghi diễn biến. Đơn vị bộ nhớ MiB; CPU dùng null. Thời gian khởi tạo/tải trọng số tách riêng; vòng đầu không đại diện chắc chắn cho tốc độ ổn định.
